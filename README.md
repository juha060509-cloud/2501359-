스마트 대학 학점 계산기 Pro는 4.5와 4.3 만점 기준을 모두 지원하며, 전공과 교양 구분 관리, 학기별 필터링, 목표 평점 시뮬레이터, 백업 및 내보내기 기능을 갖춘 웹 기반 성적 관리 프로그램입니다. 사용자는 4.5 또는 4.3 만점 체계와 라이트·다크 모드를 선택한 뒤, 학기, 이수 구분, 학점, 성적 등급, 과목명을 입력해 과목을 추가할 수 있으며, 등록된 과목은 모달 창으로 수정하거나 삭제할 수 있고 학기 탭별로 나누어 조회할 수 있습니다. 평점은 P(Pass) 과목을 제외하고 가중 평균 GPA와 환산 백분율 점수로 자동 계산되며, 전체 GPA와 전공 GPA, 등급별 분포 차트가 화면에 함께 표시됩니다. 또한 목표 평점과 남은 학점을 입력하면 앞으로 취득해야 할 평균 평점을 계산해 주는 시뮬레이터가 제공되고, 입력한 데이터는 브라우저 localStorage에 자동 저장되며 예시 데이터 불러오기, CSV 다운로드, JSON 백업 및 복원, 인쇄, 전체 초기화 기능을 통해 편리하게 관리할 수 있습니다.
