# 🎓 스마트 대학 학점 계산기 & 성적 관리 시스템 (Pro v2.0)

C++ 콘솔 성적 관리 프로그램(`SubJect/subject.cpp`)의 핵심 기능을 대폭 확장하여 대학생의 실질적인 성적 관리 및 졸업·취업 사정에 필요한 모든 기능을 웹 브라우저에서 편리하게 사용할 수 있도록 구현한 종합 웹 애플리케이션입니다.

---

## 🚀 빠른 실행 방법

1. **원클릭 실행**:
   - 프로젝트 폴더의 `start_web.bat`을 더블 클릭하거나,
   - `index.html` 파일을 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 엽니다.

2. **로컬 서버 구동 (선택 사항)**:
   ```bash
   python -m http.server 8080
   ```
   브라우저에서 `http://localhost:8080` 접속

## 🌟 이번 업데이트(Pro v2.0)의 주요 개선 사항

### 1. 🎯 전공 평점 (Major GPA) vs 전체 평점 (Total GPA) 분리 분석
* 취업 지원 및 졸업 요건 심사에서 가장 중요한 **전공 평점**을 별도로 집계합니다.
* 과목 등록 시 `전공`, `교양`, `일반` 이수 구분을 원클릭으로 지정할 수 있습니다.

### 2. ⚖️ 4.5 만점 / 4.3 만점 체계 실시간 전환
* 대학교별 학점 기준에 맞추어 **4.5 만점**과 **4.3 만점**(서울대, 연세대 등)을 상단 토글 버튼으로 즉시 전환합니다.
* 만점 체계 변경 시 등록된 모든 과목의 평점이 자동으로 재계산됩니다.

### 3. 🗓️ 학기별 성적 관리 및 필터링
* 1학년 1학기(`1-1`)부터 4학년 2학기(`4-2`), 계절학기까지 학기별로 과목을 구분하여 저장합니다.
* 상단 학기 탭을 통해 **특정 학기의 성적만 필터링**하여 확인하거나 전체 누적 성적을 조회할 수 있습니다.

### 4. ✏️ 과목 정보 수정 (Edit Modal) 지원
* 오입력한 과목명, 학기, 이수 구분, 학점, 성적을 삭제 후 재입력할 필요 없이 **수정(✏️) 버튼**을 눌러 즉시 변경할 수 있습니다.

### 5. 🎯 목표 졸업 평점 시뮬레이터 (Goal GPA Simulator)
* "앞으로 남은 30학점 동안 몇 점을 받아야 졸업 평점 4.0을 넘길 수 있을까?"
* 목표 평점과 남은 학점을 입력하면 **앞으로 받아야 할 평균 학점을 실시간으로 계산**해 드립니다.

### 6. 🌙 모던 다크 모드 (Dark Mode) 지원
* 야간 과제나 학습 시 눈의 피로를 줄여주는 세련된 다크 테마를 탑재했습니다.

### 7. 💾 데이터 백업 및 복원 (JSON Import/Export)
* 브라우저를 이동하거나 PC를 교체해도 작성한 성적 데이터를 JSON 파일로 다운로드하고 언제든지 복원할 수 있습니다.
* 엑셀에서 바로 열 수 있는 **CSV 내보내기**와 **인쇄/PDF 출력**도 완벽 지원합니다.
